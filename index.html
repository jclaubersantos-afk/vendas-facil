Backup dos dados

Os dados ficam armazenados localmente neste navegador/celular. Após salvar o fechamento em PDF, o Vendalume perguntará se você quer fazer um backup. No aplicativo Android, o arquivo vai para Downloads com data e hora no nome.

Copie o texto e guarde numa nota segura antes de reinstalar o app. Depois, cole-o aqui para restaurar os dados.

Importar backup substitui os dados atuais. Guarde o arquivo exportado em local seguro.
